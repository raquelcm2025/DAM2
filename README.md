El presente proyecto tiene como objetivo el desarrollo de una aplicación móvil iOS denominada “Mis Tareas”, orientada a mejorar la organización académica de los estudiantes de Cibertec, especialmente aquellos que cursan ciclos avanzados y enfrentan múltiples responsabilidades simultáneas. La aplicación permite gestionar tareas académicas mediante el registro, visualización, seguimiento y control del estado de cada actividad, integrando funcionalidades como categorización por curso, establecimiento de fechas de entrega y actualización del progreso.
El desarrollo se realizó utilizando tecnologías como Swift en el entorno Xcode, con el uso de Storyboard para la interfaz de usuario, Core Data para la persistencia local de datos y servicios REST para la sincronización de información. El proyecto alcanzó un 80% de implementación funcional, permitiendo validar su utilidad y aplicabilidad en contextos académicos reales. Asimismo, se evidencia que la solución propuesta contribuye a mejorar la organización, puntualidad y productividad de los estudiantes.
